# EngiCalc

**Инженерные расчёты: электрика, КИПиА, автоматика**

Кроссплатформенное десктопное приложение на Qt 6 для инженерных расчётов в области электрики, контрольно-измерительных приборов и автоматики.

## О приложении

EngiCalc предоставляет набор калькуляторов для типовых инженерных задач:

- Электрические расчёты (сети до 1000 В)
- Расчёты КИПиА (контрольно-измерительные приборы и автоматика)
- Нормативная база: ПУЭ, ПТЭЭП, ГОСТ

## Технологии

| Компонент | Технология |
|-----------|------------|
| Фреймворк | Qt 6 (Widgets, Core, Gui, PrintSupport, Svg) |
| Сборка | CMake ≥ 3.19 |
| Язык | C++17 |
| Тесты | GoogleTest + GoogleMock |
| Документация | Doxygen |
| Локализация | Qt Linguist (русский + английский) |

## Сборка

```bash
cmake -B build
cmake --build build
```

### Опции сборки

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `BUILD_TESTS` | ON | Сборка тестов |
| `BUILD_KIPIA` | ON | Модуль КИПиА |

### Запуск тестов

```bash
cmake -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build
```

## Архитектура

Проект разделён на независимые модули:

```
src/
├── core/      # Расчётная логика (static lib, без Qt Widgets)
├── kipia/     # Расчёты КИПиА (static lib, опционально)
├── ui/        # Виджеты, диалоги, лендинг
├── models/    # Табличные модели, справочники
├── report/    # Экспорт CSV/PDF, сохранение проекта (JSON)
└── util/      # Утилиты: конвертеры, константы, тема
```

**Ключевой принцип:** вся математика живёт в `core`/`kipia` как чистые функции без зависимости от UI. Это позволяет покрывать все формулы юнит-тестами без GUI.
