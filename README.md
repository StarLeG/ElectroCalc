# EngiCalc

**Инженерные расчёты: электрика, КИПиА, автоматика**

Кроссплатформенное десктопное приложение на Qt 6 для инженерных расчётов в области электрики, контрольно-измерительных приборов и автоматики.

## О приложении

EngiCalc предоставляет набор калькуляторов для типовых инженерных задач:

- Электрические расчёты (сети до 1000 В)
- Расчёты КИПиА (контрольно-измерительные приборы и автоматика)
- Нормативная база: ПУЭ, ПТЭЭП, ГОСТ

## Технологии

| Фреймворк | Qt 6 (Widgets, Core, Gui, PrintSupport, Svg) |
| Сборка | CMake ≥ 3.19 |
| Язык | C++17 |
| Тесты | GoogleTest + GoogleMock |
| Документация | Doxygen |
| Локализация | Qt Linguist (русский + английский) |

## Сборка

```bash
cmake -B build
cmake --build build
```

### Опции сборки

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `BUILD_TESTS` | ON | Сборка тестов |
| `BUILD_KIPIA` | ON | Модуль КИПиА |

### Запуск тестов

```bash
cmake -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build
```

## Веб-версия

Сайт `engicalc.electroman.by` собирается из одного мастер-файла: каждый
калькулятор получает собственный адрес и страницу.

```bash
npm run build     # web/_master.html -> web/<раздел>/index.html, витрина, sitemap, прекэш
npm run check     # заголовки, описания, ссылки меню и прекэш service worker
```

**Разметку правят только в `web/_master.html`.** Файлы `web/index.html` и
`web/<раздел>/index.html` собираются генератором, и правки в них теряются при
следующей сборке.

```
web/_master.html          разметка всех калькуляторов — исходник сборки
web/js/data/pages-meta.js список разделов: адрес, заголовок, описание
web/js/data/help-data.js  тексты справки (их же вставляет генератор)
tools/build-pages.mjs     сборка страниц
tools/check-pages.mjs     проверки перед выкладкой
```

Тесты калькуляторов (юнит и браузерные, Playwright) — в `tests/web/`,
запуск и устройство описаны в [tests/web/README.md](tests/web/README.md):

```bash
npm run test:unit   # чистые функции и справочные таблицы
npm run test:e2e    # калькуляторы в браузере
```

Выкладка: `deploy-web.ps1` сам запускает проверку и откажется заливать сайт,
если страницы собраны не из текущего мастер-файла.

## Архитектура

Проект разделён на независимые модули:

```
src/
├── core/      # Расчётная логика (static lib, без Qt Widgets)
├── kipia/     # Расчёты КИПиА (static lib, опционально)
├── ui/        # Виджеты, диалоги, лендинг
├── models/    # Табличные модели, справочники
├── report/    # Экспорт CSV/PDF, сохранение проекта (JSON)
└── util/      # Утилиты: конвертеры, константы, тема
```

**Ключевой принцип:** вся математика живёт в `core`/`kipia` как чистые функции без зависимости от UI. Это позволяет покрывать все формулы юнит-тестами без GUI.
