## 2. SVG-примитивы

Каждый элемент схемы — отдельная функция, возвращающая SVG-строку:

| Функция | Что рисует |
|---------|-----------|
| `wire(pts)` | Провод через массив точек `[[x1,y1],[x2,y2],...]` |
| `dot(x,y)` | Точка соединения (зелёный кружок) |
| `txt(x,y,text)` | Текстовая подпись |
| `resV(x,y,label)` | Вертикальный резистор (зигзаг 60px) |
| `resH(x,y,label)` | Горизонтальный резистор |
| `capV(x,y,label)` | Вертикальный конденсатор (две пластины) |
| `capH(x,y,label)` | Горизонтальный конденсатор |
| `led(x,y)` | Светодиод (треугольник + стрелки) |
| `gnd(x,y)` | Заземление (три полосы) |
| `vdd(x,y,label)` | Источник питания (красная линия + подпись) |

## 3. Компоненты с пинами

### NE555

Возвращает `{svg, pins}`:

```javascript
function ne555(x, y) {
  const pins = {
    1: [x,    y+50],  // GND
    2: [x+20, y+50],  // Trigger
    3: [x+40, y+50],  // Output
    4: [x+60, y+50],  // Reset
    5: [x+60, y],      // Control Voltage
    6: [x+40, y],      // Threshold
    7: [x+20, y],      // Discharge
    8: [x,    y]       // V+
  };
  return { svg: svgStr, pins };
}
```

Координаты пинов используются для подключения проводов:

```javascript
const ic = ne555(160, 80);
const p = ic.pins;

// Провод от Pin7 к резистору
${wire([[p[7][0], p[7][1]], [60, 160]])}

// Провод от Pin6 и Pin2 к конденсатору
${wire([[p[6][0], p[6][1]], [p[6][0], 270]])}
${wire([[p[2][0], p[2][1]], [p[2][0], 270]])}
```

### Расположение пинов NE555 (DIP-8)

```
        ┌──────────┐
  Pin8 ─┤  NE555   ├─ Pin5
  Pin7 ─┤          ├─ Pin6
        └──────────┘
  Pin1 ─┤          ├─ Pin4
  Pin2 ─┤          ├─ Pin3
        └──────────┘
```

## 4. Схема = функция

Каждая схема — функция, возвращающая SVG:

```javascript
function circuit555Astable() {
  const ic = ne555(160, 80);  // создаём IC
  const p = ic.pins;           // берём координаты пинов
  
  const inner = `
    ${vdd(60, 30, '+V')}           // питание
    ${wire([[60,50],[60,75]])}     // провод
    ${resV(60, 75, 'R1')}          // резистор
    ${ic.svg}                      // сама микросхема
    ${wire([[p[8][0],p[8][1]],...])} // Pin8 → V+
    ${wire([[p[6][0],p[6][1]],...])} // Pin6 → конденсатор
    ${gnd(60, 330)}                // заземление
    ${txt(280, 250, 'f = ...')}    // формула
  `;
  
  return svg(460, 340, inner);    // оборачиваем в SVG
}
```

## 5. Экспорт и рендер

```javascript
export const CIRCUITS = {
  '555-astable': { 
    title: 'Астабильный режим', 
    desc: 'NE555 генерирует импульсы',
    svg: circuit555Astable,        // функция-генератор
    components: ['NE555', 'R1', 'R2', 'C'] 
  },
  // ...
};

export function renderCircuit(id) {
  const c = CIRCUITS[id];
  return `
    <h3>${c.title}</h3>
    <p>${c.desc}</p>
    <div class="svg-container">${c.svg()}</div>
    <div class="components">${c.components.join(' · ')}</div>
  `;
}
```

## 6. Как подключаются провода

IC body: `(x, y) → (x+80, y+50)`

| Pin | Координаты | Описание |
|-----|-----------|----------|
| 1 | `(x, y+50)` | GND (левый нижний) |
| 2 | `(x+20, y+50)` | Trigger |
| 3 | `(x+40, y+50)` | Output |
| 4 | `(x+60, y+50)` | Reset |
| 5 | `(x+60, y)` | Control Voltage |
| 6 | `(x+40, y)` | Threshold |
| 7 | `(x+20, y)` | Discharge |
| 8 | `(x, y)` | V+ (левый верхний) |

Провод идёт от координаты пина к координате резистора/конденсатора:

```javascript
// Pin7 (x+20, y) → junction (60, 160)
${wire([[p[7][0], p[7][1]], [60, 160]])}
```

## 7. Реализованные схемы

### NE555 (6 схем)

| Схема | Режим | Описание |
|-------|-------|----------|
| Мигающий LED | Астабильный | R1=1K, R2=470K, C=1мкФ → ~1.5 Гц |
| Метроном | Астабильный | VR1=250K для изменения темпа |
| ШИМ мотор | Астабильный | D1/D2 разделяют charge/discharge, TIP120 |
| Датчик темноты | Моностабильный | LDR + R1 делитель → Pin2 trigger |
| Сенсорный выключатель | Моностабильный | Пластина → статическое электричество |
| Сирена (двойной) | Астабильный | IC1 модулирует Pin5 IC2 через R=10K |

### Операционные усилители (3 схемы)

| Схема | Описание |
|-------|----------|
| Повторитель (Buffer) | K=1, Zin=∞, Zout=0 |
| Фильтр НЧ (LPF) | fc = 1/(2πRC) |
| Компаратор | Vin > Vref → ON |

## 8. Исправленные ошибки (v3)

| Ошибка | Исправление |
|--------|------------|
| Pin 6 не соединён с Pin2 | Теперь оба подключены к конденсатору |
| Pin 4 не к V+ | Подтянут через провод |
| Pin 5 без конденсатора | Добавлен 10nF на GND |
| Динамик без GND | Оба вывода подключены |
| Сирена: сигнал не на Pin5 | R=10K от Pin3 IC1 к Pin5 IC2 |

## 9. Как добавить новую схему

1. Создать функцию `circuitMyCircuit()` в `circuits.js`
2. Добавить запись в `CIRCUITS` объект
3. Добавить кнопку `<button class="circuit-btn" data-circuit="my-circuit">` в HTML
4. Кнопка автоматически рендерит схему при клике

```javascript
// Пример добавления
function circuitMyCircuit() {
  const ic = ne555(100, 50);
  const p = ic.pins;
  const inner = `
    ${ic.svg}
    ${wire([[p[8][0],p[8][1]],[p[8][0],30]])}
    // ... остальные соединения
  `;
  return svg(400, 300, inner);
}

// В CIRCUITS:
'my-circuit': {
  title: 'Моя схема',
  desc: 'Описание',
  svg: circuitMyCircuit,
  components: ['NE555', 'R1', 'C1']
}
```
