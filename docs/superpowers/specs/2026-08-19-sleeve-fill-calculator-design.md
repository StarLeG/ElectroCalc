# Калькулятор заполнения соединительной гильзы

Дата: 2026-08-19
Статус: согласован, к реализации

## Задача

Подобрать соединительную гильзу под набор скручиваемых в неё проводников и
показать, насколько плотно она будет заполнена. Расчёт справочный: решение о
монтаже принимает электромонтажник по каталогу производителя.

Пользователь — монтажник на объекте, часто со смартфона. Отсюда крупные поля
ввода, выпадающие списки вместо ручного набора и мгновенный результат с
цветовой индикацией.

## Ключевое ограничение: достоверность данных

**Каталожных данных по гильзам в проекте нет, и восстановить их точно нельзя.**
Диапазоны сечений, внутренние диаметры и длины будут собраны по типовому ряду и
являются приблизительными.

Это тот же случай, что и с поправочными коэффициентами ПУЭ в
`web/js/data/cable-data.js`, и решается так же:

1. все числа лежат в одном файле `web/js/data/sleeve-data.js`;
2. в шапке файла — явное предупреждение, что данные подлежат сверке с каталогом;
3. в интерфейсе — видимая плашка о справочном характере расчёта;
4. структура таблицы такая, что сверка сводится к правке одной строки на
   типоразмер, без изменения кода.

Номера стандартов (ГОСТ 23469.3, ГОСТ 9581) хранятся в данных как строки и
подлежат такой же сверке.

## Модули

```
web/js/data/sleeve-data.js   Ряд гильз, семейства, коэффициенты укладки жил
web/js/sleeve.js             calcSleeve() — чистый расчёт + DOM-обвязка страницы
```

Разделение повторяет `cable-select.js` и `led-strip.js`: расчётное ядро — чистая
функция без обращений к DOM, поэтому его можно вызвать из `tests.html`.

### sleeve-data.js

```js
export const SLEEVES = [
  { id, family, material, sMin, sMax, dIn, dOut, len, die, std },
  …
];
```

| Поле | Смысл |
|------|-------|
| `id` | Типоразмер: `ГМЛ-10` |
| `family` | Семейство: `ГМЛ`, `ГАО`, `ГАМ`, `ГМЛ-П` |
| `material` | `cu` — медь, `al` — алюминий, `bi` — медно-алюминиевая |
| `sMin` / `sMax` | Диапазон суммарного сечения жил, мм² |
| `dIn` | Внутренний диаметр, мм — по нему считается заполнение |
| `dOut` | Наружный диаметр, мм — для разреза и подбора термоусадки |
| `len` | Длина гильзы, мм |
| `die` | Матрица опрессовки |
| `std` | Стандарт или ТУ |

```js
export const SLEEVE_FAMILIES = { ГМЛ: { material, std, note }, … };
export const FLEX_FILL = { 1: 1.0, 2: 0.77, 5: 0.70, 6: 0.65 };
```

`FLEX_FILL` — доля, которую металл жилы занимает в её габарите. Монолитная жила
(класс 1) заполняет свой габарит целиком, гибкая многопроволочная (классы 5 и 6)
при том же сечении занимает заметно больше места. Величины приблизительные и
входят в тот же периметр сверки.

## Алгоритм

Вход:

```js
calcSleeve({
  conductors: [{ S, qty }],   // сечение мм², количество
  material,                   // 'cu' | 'al' | 'cu-al' — материал соединяемых жил
  flexClass,                  // 1 | 2 | 5 | 6
  family,                     // необязательно: конкретное семейство
})
```

Шаги:

1. **Суммарное сечение** — `sumS = Σ S·qty`. Это величина, по которой гильза
   подбирается в каталогах.
2. **Занимаемая площадь** — `condArea = Σ (S / FLEX_FILL[flexClass])·qty`. Она
   всегда не меньше `sumS` и используется только для заполнения.
3. **Подбор** — первая по возрастанию гильза подходящего материала (и семейства,
   если задано), у которой `sMin ≤ sumS ≤ sMax`.

   Материал жил задаёт допустимый материал гильзы: медь → `cu` (ГМЛ),
   алюминий → `al` (ГАО), соединение меди с алюминием → `bi` (ГАМ). Прямое
   соединение меди с алюминием обычной гильзой недопустимо из-за
   электрохимической коррозии, поэтому вариант `cu-al` отбирает только
   биметаллические гильзы.
4. **Заполнение** — `fillPct = condArea / (π·dIn²/4) · 100`.
5. **Добивка** — если `fillPct < 60`, считается недостающая площадь до 60 %
   и переводится в мм² проволоки, которую нужно доложить.

Выход:

```js
{ ok, sumS, condArea, sleeve, fillPct, status, matrix,
  filler, warnings, normative, messageKey }
```

### Статусы заполнения

| Диапазон | Статус | Индикация | Смысл |
|----------|--------|-----------|-------|
| < 60 % | `loose` | жёлтый | Гильза великовата, нужна добивка проволокой |
| 60…90 % | `ok` | зелёный | Норма |
| 90…95 % | `tight` | жёлтый | На верхней границе, проверить по каталогу |
| > 95 % | `over` | красный | Недопустимо, жилы не поместятся |

### Выход за пределы ряда

| Условие | Поведение |
|---------|-----------|
| `sumS` меньше `sMin` самой малой гильзы | Не отказ: возвращается наименьшая гильза со статусом `loose` и расчётом добивки |
| `sumS` больше `sMax` самой крупной | Отказ с рекомендацией разделить соединение |
| Нет ни одной гильзы выбранного семейства под материал | Отказ с указанием причины |
| Пустой список проводников или нулевые сечения | Отказ, `messageKey` для локализованного текста |

Отказ возвращается как `{ ok: false, messageKey }`, а не бросается исключением —
так же устроен `solveDC` в редакторе схем.

## Интерфейс

Страница `page-sleeve`, пункт меню в группе **КАБЕЛЬНЫЕ СЕТИ** рядом с
«Заполнение труб»: задача того же рода — влезет ли набор проводников в объём.

Разметка по образцу `page-conduitfill`:

- таблица проводников: сечение (выпадающий список из `STD_SECTIONS`),
  количество; кнопки «+ Провод» и «− Убрать»; до 10 строк;
- поля: материал жил, класс гибкости, семейство гильзы (по умолчанию — любое);
- плитки результата: типоразмер, суммарное сечение, заполнение, матрица, статус;
- предупреждения крупным шрифтом с пояснением;
- панель формулы с нормативом;
- плашка: «Расчёт справочный. Перед монтажом руководствуйтесь указаниями
  производителя гильз и требованиями ПУЭ».

Пересчёт по кнопке «Рассчитать» — как на соседних страницах.

### Разрез гильзы

Инлайновый SVG: окружность внутреннего диаметра, внутри — кружки жил,
разложенные концентрическими кольцами (центральная жила, затем кольцо вокруг
неё). Заливка кружков — по статусу заполнения, теми же токенами темы, что и
индикация. Строится вручную, как оверлей в редакторе схем; библиотеки не нужны.

Укладка колец приблизительная и служит наглядности, а не расчёту: число жил в
кольце берётся из отношения длин окружностей.

## Тестирование

В `tests.html`, импортом `calcSleeve` и таблицы.

Расчёт:

- типовые комбинации 2×2.5, 3×1.5, 4×6 — подбирается ожидаемый типоразмер;
- обе границы диапазона каждой гильзы попадают в неё, а не в соседнюю;
- сумма ниже ряда — предложена наименьшая гильза с добивкой;
- сумма выше ряда — отказ с рекомендацией разделить соединение;
- при одном и том же сечении класс 5 даёт большее заполнение, чем класс 1;
- заполнение монотонно растёт с добавлением проводников;
- добивка положительна при `fillPct < 60` и равна нулю в норме;
- нулевые и отрицательные сечения отвергаются.

Консистентность данных (защита от ошибок при сверке):

- диапазоны внутри семейства идут без дыр и без пересечений;
- `dIn` монотонно растёт вместе с `sMax`;
- `dIn < dOut` у каждой записи;
- у каждой записи заполнены `die` и `std`;
- сечения из `STD_SECTIONS` покрываются рядом хотя бы одной гильзы.

## Что не входит

| Отложено | Причина |
|----------|---------|
| Выбор производителя (КВТ, IEK, DKC) | Требует каталога на каждого; без исходных данных получится выдумка |
| История расчётов | Отдельная функция, не влияет на ядро |
| Ввод фактического диаметра жил вместо сечения | Ядро уже считает площадь; поле ввода добавляется поверх, когда понадобится |

## Риски

1. **Данные приблизительны.** Главный риск. Снимается сверкой таблицы с
   каталогом; тесты консистентности не дадут сверке внести противоречия.
2. **Коэффициенты укладки.** Влияют только на заполнение и предупреждения, на
   выбор типоразмера — нет. Ошибка здесь не приведёт к неверному подбору гильзы.
3. **Разрез — иллюстрация.** Не должен восприниматься как проверка укладки;
   подписывается соответствующе.
