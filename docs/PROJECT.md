# EngiCalc — Полная документация проекта

## Общее описание

**EngiCalc** — кроссплатформенное десктопное и веб-приложение для инженерных расчётов в области электрики, КИПиА, автоматики и электроники.

- **Сайт:** https://engicalc.electroman.by/
- **Лицензия:** LGPL v3.0
- **Автор:** Старинский Олег Григорьевич
- **Стек:** HTML5, CSS3, JavaScript (ES Modules), SVG
- **Фреймворк:** нет (vanilla JS, без зависимостей)

### Модульная архитектура

Приложение использует **ES Modules** (import/export). Каждый модуль отвечает за группу калькуляторов.

```
app.js (entry point)
  ├── core.js          ← хелперы, i18n, навигация, тема
  ├── electrical.js    ← электрика базовая
  ├── electrical2.js   ← электрика расширенная
  ├── electrical3.js   ← электрика монтаж
  ├── equipment.js     ← оборудование
  ├── cable-networks.js ← кабельные сети + конвертеры
  ├── electronics.js   ← электроника
  ├── microchips.js    ← микросхемы
  ├── kipia.js         ← КИПиА
  ├── industry.js      ← промышленные расчёты
  ├── wirecab.js       ← монтаж шкафов
  ├── circuits.js      ← SVG-схемы
  └── help.js          ← справка
```

## SVG-генератор схем

### Принцип работы

Каждая схема — JavaScript-функция, возвращающая SVG-строку.

```javascript
function circuit555Astable() {
  const ic = ne555(160, 80);  // NE555 с координатами пинов
  const p = ic.pins;           // {1:[x,y+50], 7:[x+20,y], ...}
  
  const inner = `
    ${vdd(60, 30, '+V')}
    ${resV(60, 75, 'R1')}
    ${ic.svg}
    ${wire([[p[7][0], p[7][1]], [60, 160]])}
    ${gnd(60, 330)}
  `;
  return svg(460, 340, inner);
}
```

### Примитивы

| Функция | Что рисует |
|---------|-----------|
| `wire(pts)` | Провод через массив точек |
| `dot(x,y)` | Точка соединения |
| `resV/resH` | Резистор вертикальный/горизонтальный |
| `capV/capH` | Конденсатор |
| `led(x,y)` | Светодиод |
| `gnd(x,y)` | Заземление |
| `vdd(x,y,label)` | Источник питания |
| `ne555(x,y)` | NE555 + координаты 8 пинов |
| `opamp(x,y)` | Операционный усилитель |

### Реализованные схемы (9)

**NE555 (6):** Мигающий LED, Метроном, ШИМ мотор, Датчик темноты, Сенсорный выключатель, Полицейская сирена

**ОУ (3):** Повторитель, Фильтр НЧ, Компаратор

## Интернационализация (i18n)

Двуязычная поддержка RU/EN. Переводятся:
- Навигация
- Названия калькуляторов
- Метки полей
- Кнопки
- Справка

Единственный источник переводов — объект `I18N` в `core.js`. Внешних JSON-файлов
нет: они существовали, но ни одна строка кода их не загружала, и словари
разъезжались с инлайновым. Хлебные крошки берут подписи из секции `crumb`.

Справка (`help.js`) переведена на английский частично; для непокрытых разделов
показывается русский текст.
